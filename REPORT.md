# Отчет по лабораторной работе

## 1. Выбор базы данных
В качестве СУБД была выбрана **PostgreSQL**. Основная причина — её надежность и поддержка принципов ACID, что критически важно для обеспечения целостности данных при расчете цен и работы с корзиной пользователей.

## 2. Архитектура и инфраструктура (Git Flow)
* Настроена ветвочная модель **Git Flow** (`main` — стабильная, `develop` — ветка разработки, `feature/*` — для задач).
* Создан файл `.editorconfig` для единого форматирования кода в команде.
* Настроен файл `.github/CODEOWNERS` для распределения ответственности за ревью кода.

## 3. Настройка CI/CD
* Настроен автоматический пайплайн непрерывной интеграции в `.github/workflows/ci.yml`.
* Встроена проверка кода с помощью линтера **flake8** при каждом создании Pull Request и push в основные ветки.

## 4. Разработка микросервиса
* Реализован базовый функционал корзины (`main.py`), включая добавление товаров и расчет итоговой стоимости с учетом динамических скидок.
